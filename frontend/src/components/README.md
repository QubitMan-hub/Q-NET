# UI components

| Component | What it shows |
|---|---|
| `PlayPanel.tsx` | The friendly right-hand panel: pick a world (1D, 2D, 3D), pick who stands at the spot, play one round or a hundred and compare with theory. |
| `ScenarioDialog.tsx` | The start screen with ready-made scenarios, and the **New** dialog for building a custom one. |
| `NetworkCanvas.tsx` | Participants and channels as a graph; drag to place, connect ports, auto-wire. |
| `SpaceView.tsx` | The **Geometry** tab: spacetime diagram, 2D map with the light-cone check, and the rotatable 3D view. |
| `Spacetime.tsx` | Position-against-time diagram of every message in the run. |
| `AutomatonCanvas.tsx` | A participant's state machine (expert mode). |
| `Inspector.tsx` | The **Details** tab: every setting of the selected project, participant, link, state, message or event. |
| `Dock.tsx` | Bottom tabs: result, event log, timeline, validation, console and experiments. |
| `QpvPanels.tsx` | Timing table and the honest-versus-attacks comparison. |
| `Experiments.tsx` | Repeated runs and parameter sweeps with acceptance charts. |
| `Console.tsx` | Text console for the engine's command language. |
| `ui.tsx` | Small shared pieces: form fields, sections, icons. |
