# Scripts

| Script | What it does |
|---|---|
| `build_pages.sh` | Builds the static, server-less workbench into `./site` for GitHub Pages. |
| `check_clean_install.sh` | Installs into a fresh virtual environment and checks the tests, a headless run and the server. |
| `bench.py` | Performance benchmark: cost per run and how it scales with participants and qubits. |
