# examples

Bundled example projects, generated from `library.py`. Open them from the toolbar (expert mode) or run
`qpv run <name>`.

| File | Scenario |
|---|---|
| `qpv_bb84_honest.json` | 1D QPV_BB84 with an honest prover. |
| `qpv_bb84_displaced_prover.json` | The prover claims a spot it is not at. |
| `qpv_bb84_collusion_unentangled.json` | Two attackers without entanglement. |
| `qpv_bb84_teleportation_attack.json` | Two attackers who teleport the qubit using an EPR pair. |
| `cpv_honest.json` | Classical position verification, honest prover. |
| `cpv_collusion.json` | Classical position verification broken by two colluding attackers. |
